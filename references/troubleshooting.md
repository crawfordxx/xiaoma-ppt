# 常见问题

## lint 报错怎么修

| 报错 | 原因 | 修法 |
|---|---|---|
| 文字溢出 | 字太多 | 删字（完整原文挪到 `notes`）；或者拆成两页 |
| 字号从 X 缩到 Y（build 的 ⚠️） | 字太多，引擎缩字硬塞 | 同上，删字优先 |
| 形状出界 | 手写的 `area` 超出页面 | 改 `area`，或删掉让它自动算 |
| 文字压在一起 | 版式内容太多挤到一起，或 `area` 太小 | 减少条目；换版式；检查 `area` |
| 新内容压住了模板文字 | `area` 和模板的标题/页脚重叠 | 删掉手写的 `area`；或把那个模板文字加进 `delete` |
| 模板示例字没替换 | 模板里有一个框没被识别成槽位 | 看 profile.md 找到它的 `#id`，用 `slots` 填字，或用 `delete` 删掉 |
| 标题槽空着 | 没写 `title` | 补上 `title` |
| 标题还是模板原文 | 同上 | 同上 |
| 对比度 < 3 | 文字颜色和底色太接近（常见于把浅色页的内容放到深色页） | 换 `from` 到另一种底色的内容页；或在 `tokens` 里换主色 |
| 内容页没有任何内容 | 内容页没写 `body` | 补 `body`，或换成章节页 |
| 目录有 N 项，模板只有 M 个位置 | 章节太多 | 合并章节；或者删掉目录页 |

## 模板识别不准

- **角色分错了**（比如把内容页认成了章节页）：不用改识别，直接在 deck.json 的 `from` 里指定你想用的那一页，槽位用 `slots` 按 `#id` 填。
- **主色不对**：在 deck.json 顶层 `"tokens": {"primary": "#xxxxxx", "secondary": "#xxxxxx"}`。主色应该是模板里面积最大、最有辨识度的品牌色；金色、浅黄这类在白底上看不清的颜色适合做辅色。
- **内容安全区太小或位置不对**：profile.md 里会标 ⚠️。看渲染图确认后，用 `area` 手动指定。背景图上有插画时，安全区会自动避开，这是对的。
- **槽位没认出来**（例如一个文本框是模板示例字，但不在任何槽位里）：profile.md 的表格列出了每页所有文本框和它的 `#id`，用 `slots` 填或 `delete` 删。
- **模板只有一页内容页**：所有内容页都从这一页复制，这是正常的。

## 渲染相关

- **预览里字体和 PowerPoint 不一样**：本机没有模板字体时（例如 macOS 上没有微软雅黑），`render.py` 只在预览副本里换成本机字体，交付的 pptx 里字体不变。预览里略宽或略窄是正常的，引擎估算文字宽度时已经留了余量。
- **LibreOffice 把「不换行」的标题框渲染成竖排**：这是模板框太窄 + 不换行导致的，`build.py` 会自动加宽这类框（保持对齐方式，不压到右边的 logo）。
- **找不到 soffice**：装 LibreOffice。没装也能 build，只是没有预览和对比度检查：`lint.py --no-render`。

## 配图

引擎本身不生图。需要配图时：

1. 优先用用户给的图片（`image` 版式会自动裁切铺满）。
2. 需要生成时，用任何生图模型都行，prompt 里写清楚模板的主色和风格（例如「主色 #0E9AA7，干净的白底，医疗场景，扁平插画」），生成后放进 md 的 `![](路径)`。
3. 关系图、架构图、流程图优先用版式（`process`、`cards`、`compare`）做，不要贴图片，方便后续修改。
